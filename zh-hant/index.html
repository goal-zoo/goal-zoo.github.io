Goal Zoo 是一款為兒童設計的十二碼大戰遊戲：玩家負責射門，動物園裡的動物守門員們負責撲救。它的設計初衷是讓孩子可以安全地玩，而這要從一條簡單的規則說起：這款遊戲不收集任何資訊。

本頁用淺顯的文字說明 Goal Zoo 會怎樣處理資訊，以及它不會做什麼。

重點摘要

  • 遊戲不會收集、傳送、販售或分享任何個人資料，不論是兒童的，還是其他任何人的。
  • 遊戲從不連上網路。沒有伺服器，沒有帳號，也不需要登入。
  • 遊戲中沒有廣告，沒有分析工具，也沒有追蹤，也不包含任何第三方的廣告程式碼或分析程式碼。
  • 遊戲記住的內容（例如最高紀錄和貼紙）儲存在裝置上，絕不會傳送給我們。
  • 我們會收到的個人資料，只有家長自願寄給我們的電子郵件。

我們是誰

Goal Zoo 由一位獨立開發者製作並發行，也就是應用程式商店中本遊戲頁面上顯示為供應商（開發者）的那個人。本政策中的「我們」即指這位開發者。任何與隱私有關的事宜，請寫信到聯絡方式中的地址。

遊戲會記住什麼

為了讓孩子能從上次停下的地方接著玩，Goal Zoo 會在裝置上、App 自己的儲存空間裡儲存幾項內容。這些內容都無法用來識別任何人，也都不會傳到我們這裡。

備份。存檔是 App 在裝置上的資料的一部分。如果裝置的擁有者備份裝置或換用新裝置（例如透過 iCloud 備份、電腦上的備份，或 Android 手機的裝置備份），存檔可能會包含在該備份中。這類備份由裝置擁有者及其備份服務供應商建立和控管。我們無法存取這些備份。

不連上網路

Goal Zoo 完全不會進行任何網路連線。它的畫面、動畫和聲音都由遊戲本身在裝置上產生，因此既沒有東西需要下載，也沒有東西需要傳送。在飛航模式下，它同樣可以正常運作。

分析、廣告與追蹤

一概沒有。沒有分析工具，沒有廣告，沒有當機報告工具，也沒有追蹤器。遊戲中唯一不是我們自己撰寫的程式碼，是用來繪製畫面並在裝置上執行遊戲的開放原始碼軟體（列在家長專區的「授權條款」下）；它不收集任何資訊，也不與任何人通訊。我們不為任何人建立個人檔案，也不會跨 App 或跨網站追蹤任何人。遊戲根本不收集資料，自然也沒有什麼需要您「選擇退出」的。

兒童隱私

Goal Zoo 專為兒童製作，並依照應用程式商店對兒童 App 的規定來設計，例如 App Store 的「兒童」類別。由於它不向任何人收集個人資訊，也就不會向兒童收集——這符合 COPPA（美國）、GDPR（歐盟）和 KVKK（土耳其）等兒童隱私相關法律。

遊戲中沒有聊天，沒有分享，沒有社群功能，也沒有任何發布或傳送內容的途徑。

家長專區

遊戲中的「家長專區」設有家長驗證：螢幕上會出現一道用文字寫出的乘法題，答案必須用數字鍵盤輸入。答錯後，要等一段時間才能再試，而且一次比一次久。離開遊戲時、打開隱私權政策連結時，以及一分半鐘沒有觸碰螢幕後，家長專區都會自動關閉。

這裡有聲音和震動的開關、孩子的進度摘要、重置進度的按鈕、開放原始碼授權條款，以及遊戲中唯一通往遊戲之外的東西：連往本頁面的連結，它會在裝置的網頁瀏覽器中打開。

Goal Zoo 目前沒有 App 內購買項目。如果我們日後加入，它們只能在通過這道家長驗證之後使用，並由應用程式商店處理；我們也會在它們上線之前更新本政策。

應用程式商店

Goal Zoo 透過應用程式商店發行，目前是 Apple 的 App Store。商店可能會向我們提供彙總的匿名統計資料，例如遊戲的下載次數。如果裝置的擁有者選擇與 App 開發者分享診斷資訊（在 iPhone 上：裝置設定中的「與 App 開發者分享」），商店還可能與我們分享匿名的當機報告，我們只會用它來修正錯誤。這些資訊都無法識別個人，並依商店自己的隱私權政策處理，例如 Apple 的隱私權政策。

本頁面代管於 GitHub Pages，GitHub 可能會依據 GitHub 的隱私權聲明記錄 IP 位址等標準連線資訊。頁面本身沒有分析工具，也沒有追蹤。

如果您寫信給我們

聯絡地址供家長和其他成年人使用。兒童不應寫信給我們：如果孩子有話想告訴我們，可以由家長代寫。

您寄電子郵件給我們時，我們會收到您的電子郵件地址和您在郵件中寫下的內容。我們只會用它們來回覆您，並解決您所說的問題。我們不會把您加入任何名單，不會把您的地址用於其他任何用途，也不會轉交他人：經手的只有我們，以及為我們傳送和儲存郵件的電子郵件服務。在事情解決後的12個月內，我們會刪除往來郵件；如果您提出要求，我們會更早刪除。

請不要把孩子的姓名、照片或其他個人資訊寄給我們：我們不需要這些。如果您選擇把家長專區裡的錯誤紀錄寄給我們，其中只包含一個日期和一段技術性的錯誤文字。

刪除資料

家長專區中的「重置進度」會清除已儲存的進度：最高紀錄、遇過的守門員、貼紙和總計。從裝置上刪除 Goal Zoo 會移除它儲存的一切，包括設定。在較早的裝置備份中可能仍留有一份副本，直到裝置擁有者覆蓋或刪除該備份為止。

我們從不持有任何遊戲資料，因此我們這邊沒有什麼需要刪除的。您寄給我們的電子郵件會依上文所述刪除；如果您提出要求，我們會立即刪除。

您的權利

GDPR（歐盟）和 KVKK（土耳其）等隱私法律賦予您對自己個人資料的權利：了解被保存了哪些資料、取得一份副本，以及要求更正或刪除。遊戲從不向我們提供任何個人資料，因此這些權利只可能涉及您寄給我們的電子郵件。請寫信到聯絡地址，我們會讓您查看我們保存的內容，並為您更正或刪除。我們處理這類郵件，是基於我們回覆來信者的正當利益。如果您認為我們有做得不對的地方，也可以向您所在地的資料保護機關申訴（在土耳其是個人資料保護局）。

本政策的變更

如果本政策有所變更，我們會在變更生效之前，在同一網址發布新版本，並在頁面頂端標明新的日期。
