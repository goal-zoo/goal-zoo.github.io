Goal Zoo 是一款面向儿童的点球大战游戏：玩家来射门，动物园里的动物守门员们负责扑救。它的设计初衷是让孩子可以安全地玩，而这要从一条简单的规则说起：这款游戏不收集任何信息。

本页用通俗的语言说明 Goal Zoo 会怎样处理信息，以及它不会做什么。

简要说明

  • 游戏不会收集、发送、出售或共享任何个人数据，无论是儿童的，还是其他任何人的。
  • 游戏从不连接互联网。没有服务器，没有账号，也不需要登录。
  • 游戏中没有广告，没有数据分析，也没有跟踪，也不包含任何第三方的广告代码或分析代码。
  • 游戏记住的内容（例如最高纪录和贴纸）保存在设备上，绝不会发送给我们。
  • 我们会收到的个人数据，只有家长自愿发给我们的电子邮件。

我们是谁

Goal Zoo 由一位独立开发者制作并发布，也就是应用商店中本游戏页面上显示为提供者（开发者）的那个人。本政策中的“我们”即指这位开发者。任何与隐私有关的事宜，请写信至联系方式中的地址。

游戏会记住什么

为了让孩子能从上次停下的地方接着玩，Goal Zoo 会在设备上、应用自己的存储空间里保存几项内容。这些内容都无法用来识别任何人，也都不会传到我们这里。

不连接互联网

Goal Zoo 不发出任何网络请求。它的画面、动画和声音都由游戏本身在设备上生成，因此既没有东西需要下载，也没有东西需要发送。在飞行模式下，它同样可以正常运行。

数据分析、广告与跟踪

一概没有。没有数据分析，没有广告，没有崩溃报告工具，也没有跟踪器。游戏中唯一不是我们自己编写的代码，是用来绘制画面并在设备上运行游戏的开源软件（列在家长专区的“许可证”下）；它不收集任何信息，也不与任何人通信。我们不为任何人建立用户画像，也不会跨应用或跨网站跟踪任何人。游戏根本不收集数据，自然也没有什么需要您“选择退出”的。

儿童隐私

Goal Zoo 专为儿童制作，并按照应用商店对儿童应用的规定来设计，例如 App Store 的“儿童”类别。由于它不向任何人收集个人信息，也就不会向儿童收集——这符合 COPPA（美国）、GDPR（欧盟）和 KVKK（土耳其）等儿童隐私相关法律。

游戏中没有聊天，没有分享，没有社交功能，也没有任何发布或发送内容的途径。

家长专区

游戏中的“家长专区”设有家长验证：屏幕上会出现一道用文字写出的乘法题，答案必须用数字键盘输入。答错后，要等一段时间才能再试，而且一次比一次久。离开游戏时、打开隐私政策链接时，以及一分半钟没有触碰屏幕后，家长专区都会自动关闭。

这里有声音和振动的开关、孩子的进度摘要、重置进度的按钮、开源许可证，以及游戏中唯一通向游戏之外的东西：指向本页面的链接，它会在设备的网页浏览器中打开。

Goal Zoo 目前没有 App 内购买项目。如果我们今后加入，它们只能在通过这道家长验证之后使用，并由应用商店处理；我们也会在它们上线之前更新本政策。

应用商店

Goal Zoo 通过应用商店分发，目前是 Apple 的 App Store。商店可能会向我们提供汇总的匿名统计数据，例如游戏的下载次数。如果设备的所有者选择与应用开发者共享诊断信息（在 iPhone 上：设备设置中的“与 App 开发者共享”），商店还可能与我们共享匿名的崩溃报告，我们只会用它来修复错误。这些信息都无法识别个人，并按商店自己的隐私政策处理，例如 Apple 的隐私政策。

本页面托管在 GitHub Pages 上，GitHub 可能会依据 GitHub 的隐私声明记录 IP 地址等标准请求信息。页面本身没有数据分析，也没有跟踪。

如果您写信给我们

联系地址供家长和其他成年人使用。儿童不应给我们写信：如果孩子有话想告诉我们，可以由家长代写。

您给我们发电子邮件时，我们会收到您的邮箱地址和您在邮件中写下的内容。我们只会用它们来回复您，并解决您所说的问题。我们不会把您加入任何名单，不会把您的地址用于其他任何用途，也不会转交他人：经手的只有我们，以及为我们传送和存储邮件的电子邮件服务。在事情解决后的12个月内，我们会删除往来邮件；如果您提出要求，我们会更早删除。

请不要把孩子的姓名、照片或其他个人信息发给我们：我们不需要这些。如果您选择把家长专区里的错误记录发给我们，其中只包含一个日期和一段技术性的错误文字。

删除数据

家长专区中的“重置进度”会清除已保存的进度：最高纪录、遇到过的守门员、贴纸和总计。从设备上删除 Goal Zoo 会移除它保存的一切，包括设置。在较早的设备备份中可能仍留有一份副本，直到设备所有者替换或删除该备份为止。

我们从不持有任何游戏数据，因此我们这边没有什么需要删除的。您发给我们的电子邮件会按上文所述删除；如果您提出要求，我们会立即删除。

您的权利

GDPR（欧盟）和 KVKK（土耳其）等隐私法律赋予您对自己个人数据的权利：了解被保存了哪些数据、获取一份副本，以及要求更正或删除。游戏从不向我们提供任何个人数据，因此这些权利只可能涉及您发给我们的电子邮件。请写信至联系地址，我们会让您查看我们保存的内容，并为您更正或删除。我们处理这类邮件，是基于我们回复来信者的正当利益。如果您认为我们有做得不对的地方，也可以向您所在地的数据保护机构投诉（在土耳其是个人数据保护局）。

本政策的变更

如果本政策有所变更，我们会在变更生效之前，在同一地址发布新版本，并在页面顶部标明新的日期。
